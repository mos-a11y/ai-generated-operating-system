内存设置

内存上限改动后需要重启虚拟机才生效；告警线立即生效。

分辨率和显存需要重启虚拟机才生效。每帧要传的像素量跟分辨率平方成正比：800x600 只有 1080p 的 37%，入门级处理器 / 学习机上差别非常明显。

声音

浏览器要求先点一下页面才允许发声。若没声音，先点这里任意按钮，再检查手机没静音。

安装包（.mpkg）

选 .mpkg 安装包，立刻送进虚拟机安装。装好自动弹出；失败会写清第几行有问题。安卓文件管理器若不认 .mpkg，用下面这个「选任意文件」。

声音

浏览器要求先有一次点击/按键才解锁音频。装了会发声的应用却听不到时，先点一下屏幕。

浏览器要求先点一下屏幕才允许发声。装包可用 SOUND 频率 时长，ROOT 包还能用 ROOT_BEEP / ROOT_MUTE。

安装程序

点「启动安装程序」会重启并进入图形化安装向导（选位置、复制文件、建账户）。正常开机不会再自动弹。

蓝屏测试

每个错误码都能单独测试。蓝屏上按 F1 展开技术细节（寄存器、调用栈、机器码）。

虚拟按键

每按一次计数，1.5 秒内连满 3 次就重启进入对应界面。

触控板

触控板是个独立小窗：长按顶部可拖动，拖右下角可缩放。 下面带左键 / 右键和一排快捷键。

日志小窗

点左下角的 − 或 × 会把它整块藏起来，从这里恢复显示。

U 盘

上传后可在 BIOS 的「启动设备」里选从 U 盘引导。不传就还是用 MOS 系统盘。

网络

关闭时，系统里的浏览器和网络测试一律取不到内容。

CPU 限速

填 0 或留空 = 不限。按真实时间分摊，调低后 CPU 占用立刻降下来，但开机和刷新会变慢。立即生效。

界面

小窗被关掉后，点这里就能把它找回来（不用刷新页面）。

内核日志

把日志原样送到虚拟机屏幕上的「系统日志」窗口（↑↓ 滚动、Esc 关）。不用再盯左下角那个小窗。

软件商店

开机后点「安装」，MPKG 包会直接送进虚拟机，图标立刻出现在开始菜单，不用重启。

怎么用

  1. 把 MOS.iso 拖进中间的框子，或点「选择镜像」。
  2. 等桌面出来（大约 3 秒），鼠标点图标即可开应用；单击就开，不用双击。
  3. 想敲命令：用底部输入条，或点开终端图标后直接打字。
  4. 全屏后右下角有左键 / 中键 / 右键三个圆钮，方便触屏操作。

常用命令

help 命令一览 · ls 列文件 · cat 文件名 · ps 进程 · free 内存 · open 应用
支持管道与重定向：cat README.TXT | wc、echo hi > A.TXT

快捷说明

F11 或工具条「全屏」切换全屏 · 左下角日志小窗点一下展开完整日志 · 「重启」会重新引导当前镜像

关于

MOS 从一条 512 字节的引导扇区长出来：BIOS 读引导扇区 → stage2 开 VESA 帧缓冲、开 A20、探内存 → 切 32 位保护模式 → 内核接管。窗口、任务栏、鼠标指针、点阵字模全是手写像素， 没有 libc，没有第三方代码。网页里跑的是为它手写的 x86 解释器 MOS86。
